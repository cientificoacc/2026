# Repositorio 2026 – Ciencia de Datos y Analítica Territorial  
**Agencia Catastral de Cundinamarca (ACC)**

---

## 📌 Propósito del repositorio

Este repositorio consolida los desarrollos, productos técnicos y soluciones de ciencia de datos ejecutados durante la vigencia **2026**, en el marco del fortalecimiento institucional y territorial de la Agencia Catastral de Cundinamarca.

Aquí se integran:

- Desarrollo de dashboards interactivos
- Automatización de reportes
- Análisis técnico institucional
- Documentación metodológica
- Transferencia de conocimiento
- Soporte técnico a planes y procesos estratégicos

---

# 🛠 Tecnologías Utilizadas

- Python (Pandas, Matplotlib)
- Power BI
- Google Colab
- GitHub (control de versiones)
- Word Automation (python-docx)

---

# 📊 Enfoque Metodológico

El desarrollo se basa en:

- Gobierno de datos
- Trazabilidad
- Reproducibilidad
- Documentación técnica completa
- Estandarización institucional
- Enfoque territorial multipropósito

---

# 🔐 Gobernanza y Propiedad Intelectual

Todos los productos desarrollados:

- Son activos institucionales
- Incluyen documentación técnica
- Son reutilizables y escalables
- Cumplen lineamientos de gestión documental y seguridad de la información
